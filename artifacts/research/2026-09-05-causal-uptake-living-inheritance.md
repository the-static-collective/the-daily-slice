## INFERENCE: the missing common axis is causal uptake

The strongest common distinction is not simply memory versus metabolism. It is:

```text
PRESENT != OPERATIVE
```

A source, rule, receipt, witness, transform, or retained residue may exist while no downstream process actually depends on it.

The proposed cross-stack decomposition is therefore:

```text
FORMATION
  -> CARRIAGE
  -> UPTAKE
  -> EFFECT

AUTHORITY: separate axis
```

### Formation

How did this descendant/state come into existence?

### Carriage

What attributable property, receipt, constraint, or residue crossed the transformation boundary?

### Uptake

Which downstream process actually consumed what crossed?

### Effect

What later reachable possibility, candidate set, classification, or decision changed because of that consumption?

### Authority

What scoped authority, if any, was separately constituted?

No earlier axis implies a later one, and none of the first four implies authority.

Equivalent seal:

```text
something came from you
!=
something of you crossed
!=
what crossed was used
!=
its use changed the future
!=
you therefore govern that future
```

## CANDIDATE: SELECTIVE-INHERITANCE-001

Lineage can survive while literal resemblance disappears because inheritance may be property-selective.

Each measured source property receives one typed disposition:

```text
preserved
transformed
destroyed
unknown
```

A `transformed` property must include an attributable transform road.

Example:

```text
clip luminance:
  transformed
  clip luma -> deterministic grayscale mask -> native-image region selection

literal source pixels:
  destroyed
```

Provenance asks:

> Where did this come from?

Selective inheritance asks:

> What crossed, and in what form?

No semantic interpretation is implied by the inheritance receipt.

## CANDIDATE: COLLISION-AWARE-WITNESS-001

A witness family is a projection. Distinct objects may collide under that projection:

```text
I1(X) = I1(Y)
```

without implying:

```text
X = Y
```

or:

```text
I2(X) = I2(Y)
```

When a machine invariant reaches a collision fiber, the useful next witness is one sensitive to dimensions the first measurement discarded.

Human witness is one such family when the target dimensions are perceptual and intentionally absent from deterministic receipts: coherence, mood handling, compositional fit, trust, or related experiential claims.

The human should not be asked merely to redo a machine measurement less precisely.

### First specimen

Haunted Toaster Stage A machine receipts remain machine receipts. The human PASS testimony in #257 remains human testimony. A future sibling comparison can explicitly record which witness family discriminates which dimensions.

## PROTOCOL CANDIDATE: FOREIGN-TO-NATIVE-ROLE

The useful shared grammar is not a universal assimilation runtime. It is a bounded translation protocol:

```text
FOREIGN CARRIER
  -> BOUNDED PROPERTY EXTRACTION
  -> TYPED TRANSFORM
  -> NATIVE ROLE
  -> DOWNSTREAM UPTAKE
  -> ATTRIBUTABLE EFFECT
```

Critical non-implication:

```text
PROPERTY IMPORTED
!=
ONTOLOGY IMPORTED
!=
WORLDVIEW IMPORTED
!=
AUTHORITY IMPORTED
```

A paper theorem may become a hostile fixture. A lyric may become a mnemonic. A game mechanic may become a branch experiment. Clip luminance may become topology.

The foreign carrier need not remain recognizably itself. The attributable contribution must remain traceable.
