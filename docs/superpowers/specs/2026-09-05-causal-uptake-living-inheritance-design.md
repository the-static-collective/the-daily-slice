# Causal Uptake & Living Inheritance — Design

## Status

Research/specification only. No runtime authority, semantic promotion, lineage adjudication, or cross-repository shared service is created by this document.

## Problem

Several independently executable Static Collective surfaces now expose the same missing distinctions:

- a source may be present without anything from it becoming operative downstream;
- a descendant may preserve ancestry while destroying literal resemblance;
- a hostile control may exist while the decision it is meant to constrain never consumes it;
- complete machine invariants may collide while another witness family still distinguishes the objects;
- ancestry can be attributable without creating authority over the descendant.

The design therefore separates five facts that must never be collapsed:

1. **formation** — how a descendant/state came to exist;
2. **carriage** — what attributable property crossed the transformation boundary;
3. **uptake** — which downstream process actually consumed what crossed;
4. **effect** — what later reachable possibility/decision changed because of that consumption;
5. **authority** — what scoped authority, if any, was separately constituted.

No derivation rule exists from formation/carriage/uptake/effect to authority.

## Core compression

```text
SOURCE
  -> FORMATION EDGE
  -> DESCENDANT
  -> CARRIED PROPERTY / RESIDUE
  -> DOWNSTREAM UPTAKE
  -> ATTRIBUTABLE EFFECT

AUTHORITY: separate axis
```

Equivalent warning:

```text
came-from
!=
something-crossed
!=
what-crossed-was-used
!=
its-use-changed-the-future
!=
source-governs-descendant
```

## Candidate primitives / laws

### CAUSAL-UPTAKE-001

A remembered, stored, referenced, or available item is not operative merely because it exists. Support for uptake requires an attributable downstream consumer. Support for causal effect requires a controlled intervention/removal showing that a later decision or reachable possibility differs.

Required dispositions:

- `PRESENT_NOT_CONSUMED`
- `CONSUMED_NO_DELTA_OBSERVED`
- `CONSUMED_ATTRIBUTABLE_DELTA`
- `UNRESOLVED`

The first proving ground belongs in ALEX because ORDER-SWAP-CONTROL-001 currently demonstrates a control beside the motivating comparator rather than through it. Haunted Toaster's foreign-material lifecycle provides the complementary future-pressure specimen.

### CONTROLLED-DESCENDANT-001

Given one carrier `S`, frozen context `C`, and two deterministic transforms `T1`, `T2`, a sibling pair is a controlled descendant neighborhood only when exactly one declared transform dimension differs and all other relevant inputs remain fixed.

```text
(S, C) --T1--> D1
(S, C) --T2--> D2
```

If undeclared parameters drift, the `controlled-descendant` designation must refuse.

This is an internal experimental object, not automatic proof of causal truth in an uncontrolled external world.

### SELECTIVE-INHERITANCE-001

Inheritance is property-selective and typed. Each measured source property receives one disposition:

- `preserved`
- `transformed`
- `destroyed`
- `unknown`

A `transformed` disposition must include an attributable transform road. Example: clip luminance may become a deterministic region mask while literal source pixels are destroyed.

Provenance answers **where it came from**. Selective inheritance answers **what crossed, and in what form**.

### LINEAGE-NOT-RESEMBLANCE

Cross-stack law, not a lineage adjudicator:

```text
resemblance does not constitute descent
non-resemblance does not disprove descent
```

A lineage claim must depend on witnessed formation evidence. Similarity metrics may corroborate a hypothesis but cannot manufacture a formation edge.

Transfer Packet Zero and Dogram LAPLACIAN-COSPECTRAL-STRUCTURE-001 are hostile specimens for opposite failure directions.

### ANCESTRY-NOT-AUTHORITY

Cross-stack law:

```text
parent/source --formation--> descendant
```

must not imply:

```text
parent/source --authority--> descendant
```

Any authority edge requires its own explicit grant, scope, and receipt. Source identity alone is insufficient.

### COLLISION-AWARE-WITNESS-001

When witness family `I1` maps distinct objects into the same measurement fiber, choose an additional witness family `I2` that is sensitive to distinctions intentionally or incidentally discarded by `I1`.

```text
I1(X) = I1(Y)
does not imply
I2(X) = I2(Y)
```

Human witness is one possible witness family, especially for perceptual dimensions not encoded in deterministic receipts. It is not privileged by definition and should not be asked merely to repeat a machine measurement less precisely.

### FOREIGN-TO-NATIVE-ROLE

Protocol grammar, not a universal runtime:

```text
foreign carrier
-> bounded property extraction
-> typed transform
-> native role
-> downstream uptake
-> attributable effect
```

The imported property does not silently import the source's ontology, worldview, authority, or unsupported semantics.

## Non-goals

- no generic provenance/causal graph service;
- no automatic lineage inference;
- no graph-isomorphism engine;
- no universal human-witness schema;
- no semantic promotion from recurrence;
- no parent-to-child authority inheritance;
- no claim that Toaster #261 currently supports metabolism;
- no claim that one witness family is complete.
