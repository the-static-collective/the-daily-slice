# Causal Uptake & Living Inheritance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the smallest non-authoritative cross-stack bones for causal uptake, controlled descendants, selective inheritance, collision-aware witness, lineage-not-resemblance, ancestry-not-authority, and foreign-to-native-role.

**Architecture:** Keep ownership local. The Daily Slice stores the cross-stack research synthesis and laws; ALEX owns the first real control-consumption gate; Haunted Toaster owns descendant/inheritance/witness experiments. No shared runtime or automatic promotion is introduced.

**Tech Stack:** Markdown research artifacts; existing Python experiment/test surface in ALEX; existing JavaScript/FFmpeg Video Digestion surface in Haunted Toaster.

**Spec:** `docs/superpowers/specs/2026-09-05-causal-uptake-living-inheritance-design.md`

## Global Constraints

- `authority: none` for research specimens unless an owner repository separately constitutes authority.
- No automatic lineage inference.
- No parent/source authority inheritance.
- No claim that Haunted Toaster #261 currently supports metabolism.
- No universal cross-repository runtime or service.
- No semantic promotion from recurrence, similarity, or measurement collision.
