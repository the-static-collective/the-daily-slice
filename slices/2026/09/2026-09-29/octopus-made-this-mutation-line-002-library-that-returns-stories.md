## Core loop

`STORY -> LIBRARY -> MACHINE -> ACTION -> ARTIFACT -> STORY`

- `OCTOPUS MADE THIS` contains a Free Octopus Library.
- The Free Octopus Library contains `The Book of Machines`.
- `The Book of Machines` contains folios for building, repairing, modifying, documenting, or seeding libraries.
- A real-world Return Room contains the story, machine folios, field cards, and receipts.
- A reader performs one bounded action.
- The action leaves a receipt.
- The receipt becomes inherited material for a later reader, folio, story, exhibition, or mutation.

The recursion earns its keep only when each layer leaves another layer a usable difference.

## Five nested bodies

### 1. Children's story

Wrench finds a room that preserves useful differences.

Inside is a book with an unfinished machine.

Wrench assumes the missing part is an object.

It is not.

The missing part is **whoever opens the book next**.

Wrench changes the machine, leaves a trace, and swims away.

Later another octopus enters.

The simple child-facing story works without explaining the wider system.

### 2. Free Octopus Library

An in-world recurring object.

It may hold:

- waterproof books;
- machine folios;
- salvage maps;
- diagrams;
- puzzles;
- returned field notes;
- safe artifacts;
- traces left by animals that never met.

It is a miniature Room That Remembers.

### 3. The Book of Machines

Each folio can expose:

- input;
- observed affordances;
- transformation;
- output;
- residual;
- loss;
- unknown;
- stop conditions;
- demonstrated record or explicit `PROPOSED` status.

Possible chains are not represented as executed chains.

### 4. Return Room

The real-world physical mirror.

A stewarded cabinet, tabletop room, binder station, classroom object, makerspace object, church/community object, or event installation can contain:

- `OCTOPUS MADE THIS`;
- `The Book of Machines`;
- one local field card;
- blank receipts;
- selected safe returned artifacts or diagrams.

Paper-first. No app required.

### 5. Receipt network

The network remembers **acts and artifacts**, not people as score-bearing units.

Useful identities:

- `ROOM ID`
- `MACHINE ID`
- `RECEIPT ID`

Not required:

- child profile;
- public participant identity;
- leaderboard;
- virtue score;
- collection competition.

The receipt carries the act.

## Triple-bottom-line engine

### PEOPLE

Reading becomes agency.

A child can read, observe, classify, make a bounded choice, leave a trace, and understand that somebody else may continue.

The room supports intergenerational teaching and distributed authorship without requiring two participants to meet.

### PLANET

The system must not teach that every strange object is simply trash.

Real action should begin with:

`OBSERVE -> CLASSIFY -> CHOOSE`

Possible outcomes include:

`RETURN / REPAIR / REUSE / RECYCLE / RECORD-ONLY / LEAVE-ALONE`

Unknown, hazardous, wildlife-occupied, embedded, protected, or ecologically ambiguous things can produce a successful output:

`HOLD / DO NOT TOUCH`

A cleanup pile is not the score.

### PROSPERITY

Revenue can arise from the useful loop itself:

- story books;
- machine folio packs;
- family editions;
- school/library/church/community kits;
- facilitator material;
- workshops;
- sponsored Return Rooms;
- curriculum licenses;
- exhibitions;
- maker/artist collaborations.

The stronger model is not:

> buy merchandise and we donate some money

but:

> use the publication/product and the literacy, repair, stewardship, and return activity occurs through the use itself.

## Machine Folio 001

# THE LIBRARY THAT EATS TRASH AND RETURNS STORIES

**Posture:** `PROPOSED` until a real encounter is run.

### INPUT

- one story;
- one stewarded Return Room;
- one safe material or designated cleanup/material stream;
- one reader or small group;
- one blank receipt.

### TRANSFORMATION

`READ -> OBSERVE -> CLASSIFY BY AFFORDANCE -> CHOOSE SAFE ACTION -> MAKE / REPAIR / REDIRECT / DOCUMENT -> RETURN TRACE`

### OUTPUT

- changed material state;
- changed room;
- receipt another participant can use;
- possible future story material.

### RESIDUAL

- failed builds;
- objects that should be disposed of normally;
- questions nobody answered;
- materials that could not safely be used;
- ideas for later folios.

### LOSS

- time;
- unrecoverable material;
- energy / transport;
- misunderstanding;
- any habitat disturbance caused by the activity;
- whatever the receipt format fails to preserve.

### UNKNOWN

- whether the next person will understand the trace;
- whether the object was actually improved;
- whether reuse was preferable to recycling/disposal;
- whether the activity changes behavior beyond the encounter.

### STOP

Stop when:

- the object is unknown or hazardous;
- handling would be unsafe;
- wildlife or habitat would be disturbed;
- permission is missing;
- the system requires inventing evidence;
- "reuse" creates more harm than responsible disposal;
- participation starts turning a child into a tracked optimization target.

## Failure tests

### ECO-MERCH

**Failure:** sell disposable clutter while telling readers to reduce waste.  
**Counter:** material and packaging choices are part of the receipt.

### TRASH WORSHIP

**Failure:** every found object becomes sacred craft material and the room becomes a garbage cabinet.  
**Counter:** physical return is selective; drawings, photos, and receipts can carry an object's history without storing it.

### CLEANUP AS DESTRUCTION

**Failure:** participants remove habitat, occupied objects, ambiguous material, or dangerous objects because somebody called them debris.  
**Counter:** `LEAVE-ALONE` is a first-class successful output.

### STEM KIT IN DISGUISE

**Failure:** every machine converges on the adult author's answer.  
**Counter:** expose affordances and constraints; preserve strange working mutations and useful failures.

### GAMIFIED CHILD LABOR

**Failure:** highest trash count wins.  
**Counter:** no human leaderboard and no moral score attached to collection volume.

### META EATS STORY

**Failure:** the recursive system becomes homework required to enjoy the book.  
**Counter:** the Wrench story remains complete on its own. Everything else is a door.

### NETWORK EATS ENCOUNTER

**Failure:** software becomes the project.  
**Counter:** the minimum system is a book, paper, a stewarded room, a pencil, and one safe action.
