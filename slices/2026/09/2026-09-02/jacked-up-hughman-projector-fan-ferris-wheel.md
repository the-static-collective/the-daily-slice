## RAIL 2 — THE FAN SPINS THE PROJECTOR

For the qubit toy, rank-one projectors may be written

```math
P_i = \frac12(I + \mathbf n_i\cdot\boldsymbol\sigma).
```

Now distribute projector orientations broadly around the sphere.

If their directions average isotropically,

```math
\frac1N\sum_i \mathbf n_i \to 0,
```

then their **naive average projector** becomes

```math
\bar P = \frac12 I.
```

That average returns the same `1/2` readout for every normalized qubit state.

So a whole field of individually informative projections can become uninformative if we collapse their orientations before keeping their receipts.

This gives the keeper:

> **MORE WITNESSES != MORE KNOWLEDGE IF THEIR ORIENTATIONS ARE COLLAPSED BEFORE THE RECEIPTS ARE KEPT.**

The FAN field must therefore preserve something like:

```text
(projector identity, orientation, readout, time, relation)
```

not merely aggregate sentiment.

## RAIL 3 — THE GLASS CASE TEST

The projector lattice gives a clean control for one of the oldest decoder questions.

### A. Freeze carrier; rotate projector

```text
carrier fixed
projector changes
```

If the readout changes, the result is decoder-sensitive.

### B. Freeze projector; change carrier

```text
projector fixed
carrier changes
```

If the readout changes, the carrier changed relative to that frozen aperture.

### C. Rotate both together

For the quantum-state toy:

```math
\rho' = U\rho U^\dagger,
\qquad
P' = UPU^\dagger.
```

Then

```math
\operatorname{Tr}(\rho'P')
=
\operatorname{Tr}(\rho P).
```

So enormous coordinate motion can preserve the relational observable when carrier and decoder co-transform.

Hard seal:

> **MEASURE RELATIVE ORIENTATION BEFORE DECLARING WHICH SIDE MOVED.**
