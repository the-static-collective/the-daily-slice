## Deliberately wrong can still be useful

A broken decoder does **not** become evidence for the interpretation it emits merely because it was useful in an experiment.

The useful distinction is:

```text
wrong decoder
!=
evidence for wrong reading
```

but:

```text
controlled decoder perturbation
+
comparison
=
evidence about decoder sensitivity
```

Suppose baseline decoder `D0` produces result `R0`.

Change only segmentation:

```text
D1 -> R1
```

If `R1` differs sharply from `R0`, segmentation is load-bearing for that result.

Change only orientation:

```text
D2 -> R0
```

Then that property is invariant to this orientation perturbation.

A decoder does not have to be semantically correct to function as a **controlled probe of dependency**, provided its transformation is explicit and its output is not laundered into evidence.

This becomes the ALEX method candidate `MADDCL0WN-001`.
