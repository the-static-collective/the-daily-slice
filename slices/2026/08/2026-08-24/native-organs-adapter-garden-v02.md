# Native organs, adapter garden v0.2

**Date:** 2026-08-24  
**Status:** OBSERVATION / ARCHITECTURE REVISION

## What was noticed

A previously proposed four-service setup — GitLab, PostHog, Cloudflare, and Linear — was revisited after a day of substantial internal growth across the Static Collective.

The original proposal treated the four services as potentially important organs:

- GitLab as a foreign forge;
- PostHog as empirical witness;
- Cloudflare as public encounter membrane;
- Linear as commitment / frontier queue.

The fresh pass found that several of those functions have since become native inside the Collective itself.

Free Graph now provides a portable non-sovereign relational substrate and a promotion / invariance crucible. WORLDSEED now provides local-first world state, persistence, writer-facing inhabitation, tests, CI, and receipts. Derek Derrick Dark has opened Day Zero as a living continuity/worldline specimen. Daily Slice itself now carries chronology, capture/postcard architecture, and a radio-return loop.

The result is not “finish the setup later.” It is a revision of what those external systems are for.

> **Native organs first. Adapters only when a real pressure appears.**

## The revision

### GitLab — keep, but as a specimen of foreignness

GitLab still has a useful role, but not as a second canonical home and not as a required mirror.

Its strongest use is deliberate independent reconstruction:

```text
GitHub-owned source cut
        ↓
foreign reconstruction / CI
        ↓
GitLab-owned encounter testimony
        ↓
optional return for local adoption decision
```

The later Freeport / Crossing Discipline work now owns the law that this experiment tests.

Therefore:

> **GitLab may witness foreignness. It does not own foreignness.**

No setup is required until an actual foreign-forge specimen is worth running.

### PostHog — keep, but only after encounter exists

PostHog remains a strong fit for empirical runtime observation: explicit behavior, failures, latency, experiments, and feature-flagged reversible trials.

It should attach to something genuinely alive — for example Haunted Toaster field use, an inhabitable public Room, Storyship tooling, or another real encounter surface.

Its boundary remains strict:

```text
observed behavior != receipt
analytics != provenance
frequency != promotion
popularity != authority
```

Telemetry should follow encounter rather than precede it.

### Cloudflare — keep, sharply reduced to porch

Later Inhabitable Code / Room work corrected the earlier larger Cloudflare proposal.

The current intended first public projection is small and stateless:

```text
/world
/rooms/tranchnode
/rooms/tranchnode.json
/rooms/project0
/rooms/project0.json
```

No KV, D1, Durable Objects, R2, graph database, or paid stateful feature is required by v0.

Cloudflare is therefore best treated as an optional replaceable projection adapter:

> **Cloudflare is the porch, not the house.**

It earns more machinery only when a real public Room requires it.

### Linear — remove from the architecture for now

The old proposal gave Linear the job of answering:

> What have we actually admitted that we intend to do?

That looked like a missing layer at the time.

The newer system now has a stronger native path:

```text
idea / weirdness
        ↓
GitBook Incubator / conversation
        ↓
Free Graph relations + tests
        ↓
Daily Slice temporal preservation
        ↓
promotion / explicit decision
        ↓
GitHub issue / PR / implementation
        ↓
constituted repository state
```

Daily Slice can preserve what mattered without claiming it became committed work. GitHub can hold work that actually crossed into implementation. Adding Linear now would create another state projection that would itself need reconciliation.

Therefore:

> **No Linear until a real cross-repository coordination failure proves that the function is missing.**

## Why this matters

The old proposal was still useful: it identified four real functions.

What changed is that the ecosystem subsequently grew enough internal structure to distinguish **native law and memory** from **replaceable carriers and observers**.

This yields a simpler architecture:

```text
                  THE WORK ITSELF
                        │
       ┌────────────────┼────────────────┐
       ▼                ▼                ▼
    GitHub           GitBook         Free Graph
       │                │                │
       └───────────┬────┴────┬───────────┘
                   ▼         ▼
              Daily Slice  Worlds
                        │
                 public encounter
                        │
         ┌──────────────┼──────────────┐
         ▼              ▼              ▼
    Cloudflare       PostHog        GitLab
      porch          observer     foreign test
```

Linear is intentionally absent until observed coordination pressure earns it.

## Epistemic split

**Documented fact:** Free Graph, WORLDSEED, Derek Derrick Dark, and Daily Slice all acquired new executable or durable architecture on 2026-08-24; current GitBook material explicitly treats Cloudflare and comparable systems as optional adapters rather than canonical eCODE semantics.  
**Inference:** Linear's previously proposed commitment-queue role is no longer demonstrated as a missing function, because Daily Slice + GitBook + Free Graph + GitHub now cover the relevant distinctions without another state system.  
**Speculation:** GitLab and PostHog may become unusually valuable precisely because they stay external: one as foreign reconstruction pressure, the other as empirical observation of real encounters.
