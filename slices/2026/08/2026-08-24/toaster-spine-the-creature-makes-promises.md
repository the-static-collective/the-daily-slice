**Date:** 2026-08-24  
**Status:** CURRENT SEQUENCE + CANDIDATE CREATIVE ARCHITECTURE

## What changed

A pair of Toaster thoughts snapped together.

The first was operational and immediate:

```text
RIGHT NOW

#224 — promote the witnessed field spine onto current main
   ↓
reconcile the branches built against the older spine
   ├── #222 VIDEO EATING
   └── #218 memory rescue
   ↓
next fresh feature work
   └── #176 LINEAR v3
```

The second was architectural:

> What if the Toaster had a Listener-like pass for the creative field itself — not to discover lyric timing, but to notice where the song-world carries unusually strong creative pressure, place machine-owned creative landmarks, make a rough draft, witness what actually happened, and then re-enter only the places where the first pass taught it something?

The answer became **Toaster Spine**.

The important correction is that machine-created points should not be called human-style anchors.

Human anchors already mean authority.

The Toaster needs something weaker and more generative:

```text
LANDMARK
   ↓
VOW
   ↓
DEBT
   ↓
WORLD
   ↓
WITNESS
   ↓
RECEIPT
   ↓
RECOMPOSE
```

A human anchor says:

> **This may not move.**

A creative landmark says:

> **Something matters here.**

A creative vow says:

> **This is the relationship I intend to make consequential.**

A witness receipt says:

> **This is what actually became true.**

Those are different authority classes and should remain different.

# II. The vocabulary hiding in the machine

A second inventory clarified that Toaster already has a surprisingly strong low-level expressive alphabet.

## Motion

```text
still
/drift
/pulse
/orbit
/fracture
/dance
/shiver
```

## Palette

```text
garment
/analogous
/split-complement
/duotone
/underwater
/forest-floor
```

## Material

```text
clean
/grain
/photocopy
/gate-weave
/wet-thing
/FIRE
```

## Camera

```text
locked
/drift
/push
/orbit
/wobble
/bend
```

These should not automatically become a giant knob wall.

The important observation is that they already behave like a **conjugatable creative vocabulary**.

A candidate can say different things using the same source because independent axes can take different stances at different times.

For example:

```text
motion:    still
palette:   underwater
material:  photocopy
camera:    orbit
```

is not merely four settings.

It can become a sentence:

> The field refuses to move, the color sinks, the material decays into copies, and the camera alone continues searching.

Likewise:

```text
motion:    fracture
palette:   garment
material:  FIRE
camera:    locked
```

can mean:

> The world breaks while the witness refuses to flinch.

The creative gain is not primarily more options.

It is **relationship between options**.

That points directly at the post-WALK axis-grammar discovery already preserved in Toaster: evidence, stance, scope, attention, envelope, material, and consequence can compose without adding another monolithic effect family.

The simpler visible vocabulary above can therefore remain an artist-facing language while the deeper axis grammar carries causal precision underneath it.

# III. The creative Listener

The lyric Listener already discovered a strong general pattern:

```text
survey
   ↓
establish trustworthy landmarks
   ↓
partition uncertain spans
   ↓
reconstruct within bounded regions
   ↓
preserve unresolved fog
```

Toaster Spine applies that geometry to **creative causality**.

Not:

```text
Where was this lyric sung?
```

but:

```text
Where does this song-world contain unusually consequential creative pressure?
```

The first pass listens across admitted evidence:

- song structure;
- energy / transient / vocal-salience lanes;
- canonical timed lyrics where available;
- unresolved lyric influence where explicitly non-temporal;
- image/color/material evidence;
- accepted Video material when lawful;
- candidate history and memory when separately admitted;
- current topology / primitive structure;
- locks and human anchors.

It emits a sparse set of **Creative Landmarks**.

Example:

```text
LANDMARK 05
window: 62.1–65.8s

observed pressure:
- sectional release
- lyric semantic field: fracture / body / spine
- transient pressure falling
- vocal salience high
- previous field unusually still

claim:
SOMETHING MATTERS HERE

authority:
evidence only
```

The landmark does not say what must happen.

It merely reduces the size of the creative search problem.

# IV. Creative Vows

At selected landmarks, a candidate may make a **Creative Vow**.

A vow is not a renderer command.

It is an upstream relationship the candidate intends to make perceptible.

Example:

```text
VOW 05

at landmark:
sectional release + structural lyric pressure

stance:
OPPOSE

creative sentence:
"When the music resolves,
do not visually resolve with it."

possible expression:
motion: still
camera: orbit
material: photocopy
palette: analogous → drained

scope:
bounded center-left field

intended consequence:
SCAR
```

The renderer remains responsible only for executing the accepted plan.

The vow belongs upstream in candidate / score derivation.

This preserves the established membrane:

```text
evidence ≠ proposal
proposal ≠ admission
intention ≠ execution
execution ≠ witness
witness ≠ authority
```

# V. Creative Debt

The strongest new idea is that a vow may remain unresolved for a while.

That creates **Creative Debt**.

```text
VOW
   ↓
first attempt
   ↓
partial consequence
   ↓
carry unresolved relation forward
   ↓
later opportunity
   ↓
FULFILL / TRANSFORM / REFUSE
```

This turns long-form coherence into causal accounting.

Instead of ordinary recurrence:

```text
chorus returns
→ repeat motif
```

Spine can support:

```text
chorus 1
→ opens a promise

chorus 2
→ complicates the promise

chorus 3
→ pays the debt
```

The visual world therefore gains history without every subsystem having to be in the same phase at the same time.

Motion might already be resolving one debt while camera opens another and material carries residue from a third.

The world stays coherent because those events remain in lawful relation, not because they all move in lockstep.

# VI. Rough world → Witness

The first accepted composition becomes a **rough world**.

That world should then be observed as new evidence.

This is not a generic quality critic.

A generic critic tends toward:

```text
desired output
-
actual output
=
error
```

That risks converging the Toaster into a sterile optimizer.

Spine instead needs a **Witness**.

Witness asks whether each vow became materially legible and whether anything unexpected became valuable.

Minimal witness vocabulary:

```text
FULFILLED
TRANSFORMED
DROWNED
CONTRADICTED
OPEN
REFUSED

+ ACCIDENTAL GOLD
```

Example:

```text
VOW:
create tension without becoming loud

ROUGH WORLD:
camera surrendered
field narrowed
small repeated source fragment appeared

WITNESS:
TRANSFORMED

reason:
intended tension became legible,
but the strongest mechanism was not the predicted one

ACCIDENTAL GOLD:
repeated source fragment
```

The last category matters enormously.

**Accidental Gold** gives the system a formal way to say:

> I did not predict this. It is better than the correction I would have made. Preserve it.

That protects surprise from the second pass.

# VII. Recompose, do not reroll

The second pass should not regenerate the whole world.

It should use the same bounded-reentry geometry already proven useful by Listener:

```text
rough world
   ↓
witness receipts
   ↓
identify failed / open causal island
   ↓
reopen only lawful descendants of that island
   ↓
preserve human anchors
preserve successful vows
preserve accidental gold
preserve unrelated identity
   ↓
final world
```

Conceptual example:

```text
LANDMARK A ─ VOW ─ world event
                    └─ FULFILLED
                       FREEZE

LANDMARK B ─ VOW ─ world event
                    └─ DROWNED
                       REOPEN BOUNDED DESCENDANTS

LANDMARK C ─ no vow ─ strange emergent event
                       └─ ACCIDENTAL GOLD
                          PRESERVE
```

This is the visual equivalent of anchor-island Re-listen.

The world does not get erased because one region failed.

The creature learns locally from consequence.

```text

+ same vows
= same rough world

same rough world
+ same witness policy
= same witness receipts

same witness receipts
+ same revision policy
= same final world
```

## Hostile controls

```text

→ final reverts to ordinary rough-world semantics

wrong rough-world identity
→ Witness evidence refuses

human lock conflicts with revision
→ revision refuses

Accidental Gold marked preserve
→ second pass may not optimize it away

unrelated causal island

```

If that survives, the Toaster has crossed a real threshold.

It is no longer merely generating a visual response from a song.

It can:

> **listen, make an artistic promise, live through the consequence, remember what actually happened, and make its next decision from the difference.**
