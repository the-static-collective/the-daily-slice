## 1. APERTURE-PROBE survived — and produced a new thing

Start with one underdetermined carrier.

Two declared decoders read it differently:

```text
same carrier
    ↓
decoder A -> alpha
decoder B -> beta
```

Dogram sees the first declared difference at the projection boundary.

Then add one new independently declared constraint.

```text
same carrier + constraint K
    ↓
decoder A -> gamma
decoder B -> gamma
```

The disagreement disappears.

But the earlier disagreement remains historically true.

That gave us:

## `APERTURE-COALESCENCE-001`

> **MORE WITNESS CAN COLLAPSE DECODER DISAGREEMENT WITHOUT REWRITING THE OLD DISAGREEMENT.**

This matters because convergence after clarification is not proof that the earlier readers were secretly saying the same thing.

The aperture changed.

The historical projections did not.

```text
later agreement
!=
earlier identity
```

But Dogram cannot decide the second step.

## 3. CONVERGENCE-ANATOMY also stayed out

The original urge was to measure whether two discoveries were independent.

That is too coarse.

The useful object is the typed overlap between their formation ancestries:

```text
shared source?
shared decoder?
shared prompt/context?
shared human suggestion?
shared method?
direct ancestry?
unknown ancestry?
```

There should not be one magic independence score.

The overlap anatomy itself matters.

Dogram can compare two already-declared ancestry surfaces.

It cannot manufacture the ancestry.

So:

```text
recurrence != independent birth
low known overlap != proven independence
same result != same road
```

`CONVERGENCE-ANATOMY-001` remains HOLD until ALEX / 3rdi can hand Dogram attributable formation sets.

## 4. The Compass lost its needle

This was the fattest surprise.

For a frozen pair `(x,y)` and a finite declared probe family `P`, we asked which probes actually distinguish the pair:

```text
D(x,y) = { p in P | p(x) != p(y) }
```

Frozen specimen:

```text
prime_count_like -> SAME
coarse_label     -> SAME
tau_like         -> DIFFERENT
parity_like      -> DIFFERENT
```

Both distinguishing probes had the same declared minimum cost.

There was no lawful unique winner.

So the run produced:

## `DISCRIMINATOR-TIE-FIBER-001`

> **THE NEXT BEST QUESTION MAY BE A SET, NOT A NEEDLE.**

The Compass metaphor had been leaning toward:

```text
residual -> best next probe
```

The harder formulation is:

```text
residual -> minimum lawful discriminator fiber
```

If several probes are equally minimal, preserve all of them.

Do not silently choose one and backfill inevitability.

That is a tiny correction with large consequences for MADDCL0WN, active research, and any future experiment-selector.

```text
best next question
may be
{q1, q2, q3}
```

The answer can legitimately be:

> **there are three equally cheap ways to find out.**

## 5. Decoder migration got teeth

The time-loop idea also survived ordinary calculation.

Take one historical carrier `C0`.

At the historical cut:

```text
D0(C0) = unresolved
```

Later, with a richer decoder:

```text
D2(C0) = relation-R-visible
```

Replay the historical decoder later:

```text
D0(C0) = unresolved
```

exactly as before.

So later understanding can genuinely expose a new relation in an old artifact without changing either:

- the old carrier;
- the old projection available under the old decoder.

That gives the time-loop practice a very boring skeleton:

```text
immutable carrier
x
migrating decoder
=
new attributable projection
```

Not retrocausality.

Not backdated knowledge.

Not “we knew it all along.”

Just a later decoder standing somewhere the earlier decoder could not stand.

## 6. The pretty inverse-flow idea got killed

This was the necessary MADDdogcl0wn casualty.

The earlier image was:

```text
exterior moves forward
interior moves inverse
same exterior return
interior keeps the journey
```

That is not true from inverse-ness alone.

For a stateless invertible transport `T`:

```text
T^-1(T(v)) = v
```

Exactly.

We tested a concrete noncommuting matrix pair:

```text
A = [[1,1],[0,1]]
B = [[1,0],[1,1]]
v = [1,2]^T
```

Forward:

```text
B A v = [3,5]^T
```

Exact inverse return:

```text
A^-1 B^-1 (B A v) = v
```

But change the return order:

```text
B^-1 A^-1 (B A v) = [-2,7]^T
```

So the surviving mathal is not:

```text
inverse interior = memory
```

It is:

## `INVERSE-IS-NOT-MEMORY-001`

> **EXACT INVERSE TRANSPORT CANCELS. MEMORY REQUIRES A DECLARED PLACE FOR HISTORY TO LIVE.**

A nonzero return receipt needs something real:

```text
noncommuting / changed order
explicit state
explicit path history
coupling
loss / projection / quotient
non-inverse return map
```

This correction actually makes the tube/braid model better.

The interesting thing was never “inverse” by itself.

It was the possibility that the carrier closes while another retained coordinate does not.

That second coordinate must be declared.

No ghost memory.

## New MADDdogcl0wn questions

The run leaves several excellent next holes:

### 1. Can discriminators themselves be quotiented?

Two different probes may partition the live hypothesis set identically.

If so, the true “next question” object may be an equivalence class of probes, not merely a tied list.

### 2. Does aperture coalescence have a minimum witness?

If two decoders disagree, what is the smallest added constraint that makes their projections coincide?

That is almost the inverse problem of discriminator selection.

### 3. Can lift be attacked by removing held-out consequence classes?

A coherent whole may look generative only because the held-out test family is too weak.

So perhaps LIFT needs hostile **future-family replacement**, not one successful prediction.

### 4. Can path memory be localized?

Given a nonzero loop residual, which smallest state/history coordinate is sufficient to carry it?

That would connect the killed inverse-memory intuition back to receipts without reviving the ghost.
